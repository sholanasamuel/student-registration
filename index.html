What I Learned

1. What does the action attribute do?

The action attribute specifies where the form data should be sent when the form is submitted.

2. What does the method attribute do?

The method attribute specifies how the form data should be sent, such as using GET or POST.

3. Why is GET commonly useful for a search form?

GET is useful for search forms because the search information is included in the URL, making the results easy to bookmark and share.

4. Why might POST be used for a registration form?

POST is commonly used for registration forms because it sends the form data in the request body instead of putting it in the URL.

5. Does using POST automatically make information secure?

No. POST does not automatically make information secure. HTTPS is needed to encrypt information while it is being transmitted.
